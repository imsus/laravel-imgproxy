### PR Title & Message
**Title:** feat: add fluent API methods for common operations

**Message:**
```markdown
## Summary
Adds fluent, sentence-like API methods for common image processing operations, making the package more ergonomic to use.

### New Features
- **Method Aliases**: `width()`, `height()`, `quality()`, `dpr()` as shorter alternatives to `setWidth()`, etc.
- **Format Shortcuts**: `webp()`, `avif()`, `png()`, `jpg()` for quick format changes
- **Fit Shortcuts**: `cover()`, `contain()`, `fill()` for common resize modes
- **Cache Busting**: `v()` method for CDN refreshes

### Backward Compatibility
All existing `set*` methods remain unchanged and fully supported.

### Usage Example
```php
imgproxy('image.jpg')->width(300)->height(200)->webp()->build();
```
vs. previous:
```php
imgproxy('image.jpg')->setWidth(300)->setHeight(200)->setExtension(OutputExtension::WEBP)->build();
```
```

### PR Title & Message
**Title:** feat: add short options and fallback URL configuration

**Message:**
```markdown
## Summary
Adds configuration options for URL optimization and placeholder images.

### New Features
- **Short Option Names**: `IMGPROXY_USE_SHORT_OPTIONS` config generates cleaner URLs (e.g., `/w:300/h:200/` instead of `/width:300/height:200/`)
- **Global Fallback URL**: `IMGPROXY_FALLBACK_URL` config and `->fallback()` method for showing placeholder images when source is missing

### Configuration
```php
// config/imgproxy.php
'use_short_options' => env('IMGPROXY_USE_SHORT_OPTIONS', false),
'fallback_url' => env('IMGPROXY_FALLBACK_URL'),
```

### Usage
```php
// Short options (config must be enabled)
imgproxy('image.jpg')->width(300)->build(); // /w:300/...

// Fallback
imgproxy('image.jpg')->fallback('/placeholder.jpg')->build();
```
```

```markdown
## Summary
Adds a `imgproxy()` macro to Laravel's Storage facade for seamless integration.

### New Features
- **Storage Macro**: `Storage::disk()->imgproxy($path)` automatically detects base URL
- **Smart Private URLs**: Automatically generates presigned URLs for private disks (S3, etc.)

```php
// Public disk
Storage::disk('public')->imgproxy('avatars/user.jpg')->width(100)->webp()->build();

// Private disk (S3) - automatically uses temporaryUrl()

```

### Backward Compatibility
No breaking changes. This is a purely additive feature.
